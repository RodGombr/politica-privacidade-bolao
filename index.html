Política de Privacidade - Bolão da Copa

Última atualização: 10/06/2026

1. Objetivo

Esta Política de Privacidade descreve como são coletados, utilizados e armazenados os dados dos participantes do sistema Bolão da Copa.

2. Dados coletados

O sistema coleta apenas os dados necessários para funcionamento do bolão:

  • Nome do participante;
  • Número de telefone/WhatsApp;
  • Palpites enviados para os jogos;
  • Pontuação e posição no ranking;
  • Registros técnicos de envio e recebimento de mensagens, como data, hora, status e identificadores de mensagens.

3. Finalidade do uso dos dados

Os dados são utilizados exclusivamente para:

  • Identificar os participantes do bolão;
  • Enviar mensagens relacionadas aos jogos pelo WhatsApp;
  • Registrar os palpites enviados pelos participantes;
  • Calcular pontuação e ranking;
  • Auditar o funcionamento técnico do sistema e solucionar falhas de envio ou recebimento de mensagens.

4. Compartilhamento de dados

Os dados dos participantes não são vendidos, alugados ou compartilhados para fins comerciais. As mensagens são processadas por meio da WhatsApp Business Platform da Meta, necessária para envio e recebimento das comunicações do bolão.

5. Exibição pública dos palpites e ranking

Os nomes dos participantes, palpites, pontuações e ranking poderão ser exibidos na página do bolão para acompanhamento pelos próprios participantes.

6. Armazenamento e segurança

Os dados são armazenados em banco de dados controlado pelo administrador do bolão. São adotadas medidas razoáveis para evitar acesso não autorizado, alteração indevida ou perda dos dados.

7. Retenção dos dados

Os dados serão mantidos enquanto forem necessários para a administração do bolão. Após o encerramento do bolão, os dados poderão ser excluídos ou anonimizados mediante solicitação do participante.

8. Direitos do participante

O participante pode solicitar acesso, correção ou exclusão de seus dados pessoais. Também pode solicitar sua remoção do bolão a qualquer momento.

9. Como solicitar exclusão de dados

Para solicitar exclusão, correção ou acesso aos dados, entre em contato pelo e-mail: SEU_EMAIL_AQUI.

10. Alterações nesta política

Esta política poderá ser atualizada para refletir mudanças no funcionamento do sistema ou exigências legais. A versão mais recente estará sempre disponível nesta página.
